# Rabee Studio · ربيع ستوديو

مصنع الأغاني الإعلانية والكليبات وأفكار الملتي ميديا. عرض بأسلوب آبل، واستوديو عمل بأسلوب منصات الموديلات.

- **مصنع الأغنية**: علامة + إحساس + صيغة ← فكرة، كلمات (خليجي / إنجليزي / مزيج)، توقيع صوتي يُعزف في المتصفح، خطة كليب بالتوقيت، وأوامر إنتاج جاهزة.
- **المحرك المحلي** يعمل بدون إنترنت. **Gemini** اختياري: أضف مفتاح API من زر «ربط Gemini» (يُحفظ في المتصفح فقط).

## التشغيل
افتح `index.html` مباشرة، أو فعّل GitHub Pages على هذا الفرع.
