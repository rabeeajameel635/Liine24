# غرفة الإخراج (app/)

استوديو إنتاج شخصي: أغنية + كليب + ٣ ريلز + نشر كل ٥ أيام. بيشتغل محلي على الماك.

## التشغيل
```
cd app
npm install
npm start          # يبني الواجهة ويشغّل السيرفر على http://127.0.0.1:4317
```
محتاج Node 24 أو أحدث (Node بيشغّل TypeScript مباشرة). البيانات في `~/Library/Application Support/Ghorfa/ghorfa.sqlite`، وتقدر تغيّر المكان بـ `GHORFA_DATA`.

## المكتبة
- سحب وإفلات على الشبكة، أو حط الملفات في `Inbox` جوّه فولدر البيانات وهتتسجل لوحدها.
- استيراد مشروع Higgsfield: `node server/import-higgsfield.ts <manifest.json>`. لو التحميل وقع، الملف بيفضل متسجل كمرجع بعيد، وتشغيل الأمر تاني بيكمّل.
- السقف بيتطبق وقت الاستيراد: فيديو ≤1080p وصور ≤2K في نسخة الشغل، والأصل بيفضل محفوظ زي ما هو.

## نماذج الوش
`npm run models` بينزّل SFace وYuNet من OpenCV Zoo، ويتأكد من بصمة SHA-256 بتاعة كل ملف قبل ما يحفظه.

## لوحة المقاطع
- الرئيسية = غرف الأغاني. «أغنية جديدة»: اسحب ملف الأغنية (+ SRT)، والبرنامج بيحلل الـ BPM والبيت الأول والأقسام، ويقسّم على بارات كاملة.
- مفيش زرار حفظ. كل تعديل بيتحفظ لوحده مع نسخة، و⌘Z بيرجّع.
- «جهّز للتوليد»: أدوات MCP بتستنى خطوة الاتصالات. أدوات الجسر بتطلّع كيت فيه الصور المترقّمة + prompt.txt + audio.m4a، وأي فيديو اسمه فيه كود الكيت وينزل في Inbox بيتربط بالمقطع لوحده.
- المونتاج بيصدّر FCPXML لـ Final Cut.

## البنية
- `server/`: Fastify + `node:sqlite` (FTS5). نموذج البيانات وقفل «اعتمد» في `db.ts`.
- `web/`: Vite + React. ثلاث أعمدة، وأوراق، و⌘K و⌘J، وفاتح وغامق.

الموقع (`../index.html`) وغرفة الإخراج القديمة (`../studio/`) شغالين زي ما هم لحد ما الترحيل يخلص.
