**حدود v0.1 (بصراحة):** البيانات محفوظة في متصفح الجهاز نفسه. الأدوار (مدير/محاسب) حماية برقم سري على نفس الجهاز، مش حماية سيرفر. هذا بيتحل بالمرحلة 3. لحد هداك: **نسخة احتياطية يومية** من صفحة Backup على Google Drive أو Dropbox تبعك.

## كيف تفتحه
- **على الإنترنت:** فعّل GitHub Pages للمستودع على هذا الفرع، وافتح `…/app/`.
- **على الجهاز:** أي سيرفر بسيط داخل مجلد `app` (مثلاً `python3 -m http.server`) وافتح `index.html`. فتح الملف مباشرة بدون سيرفر ما بيشغّل الوحدات البرمجية.
- أول مرة: Settings ← Switch to admin ← حط اسم الشركة ورقم المشتغل ← Set PIN.

## الربط مع الذكاء الاصطناعي (ChatGPT أو Claude أو Gemini)
صفحة **Import · Excel · AI** فيها برومبت جاهز. انسخه، حط تحته الإكسل أو صورة الطلبية أو رسالة الواتساب، وابعته للذكاء الاصطناعي. الجواب JSON بتلصقه بالبرنامج. البرنامج **بيفحصه** قبل الحفظ، والأصناف المجهولة ما بتدخل، والفاتورة بتوصل **مسودة** لازم حدا يراجعها ويرحّلها.
