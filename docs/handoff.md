# تسليم الجلسة (٦ نوفمبر ٢٠٢٦)

اقرا الملف ده أول حاجة في أي جلسة جديدة، وبعده `projects/i-am-the-world/README.md` و`app/README.md`.
الفرع: `claude/compassionate-darwin-q029ht`.

## اللي اتعمل واتعتمد

- **الواجهة:**
  - الألوان أبيض ورمادي وأخضر.
  - خطوط IBM Plex Sans Arabic وInter متدمّجة جوه البرنامج.
  - قواعد ٢٥ كلمة و١٧px و٥٦px، وبيفحصها `app/scripts/ui-audit.cjs`.
- **الإلهام:** RSS من Promonews وDirectors Notes، وClaude Code بيكتب السطر.
- **المصنع ١ · المرجع مرة واحدة (@):** الثوابت، والنسخ اللي ما بتتعدلش، وتحويل @ لكل مولد بصيغته.
- **المصنع ٢ · الفحص والتقييم:**
  - الدرجة = أضعف فحص، وأقل من ٩٥ يبقى «محتاج إعادة».
  - الفحص البصري مرة واحدة لكل SHA.
  - الوش (SFace) مستني الماك.
- **برومبت H2:** في `timeline_v44.json`. وفيه قاعدة: لو المقطع فيه دنيا ومفيش @دنيا، فيه تنبيه قبل الكيت.
- **الـ BPM:** 72.25 معتمد.
- **صور الوش A وB و«A من غير حلق»:** مقفولة. خط الأساس هو A الأصل.

## مستني «اعتمد» من ربيع

- **الاستعداد للماك:**
  - `app/mac-setup.command` و`npm run mac-setup`.
  - شاشة «أول تشغيل» (`#/setup`).
  - `docs/mac-checklist.md`.
  - `app/setup/library.json`: فهرس المكتبة من غير روابط، وبيتسحب من Higgsfield MCP بعد تسجيل الدخول.

## أسئلة مفتوحة لربيع

1. **Skywork / SkyReels:** مفيش MCP رسمي، والـ API محتاج مفتاح. الاقتراح إنه يبقى جسر (كيت + Inbox) ومعاه «غرفة مولد» فيها ٣ استخدامات:
   - حركة بشر
   - لقطة طويلة لحد دقيقة
   - أداء وغُنا
   - **مستنيين:** صور شاشة من Skywork (قايمة السكيلز، وصفحة الخطة، وشاشة الصورة لفيديو).
2. **«جوجل ستوديو»:** يقصد AI Studio (محتاج مفتاح، وVeo بيتحاسب بالثانية، والتكلفة تتعرض قبل أي توليد) ولا Flow (على الاشتراك، جسر)؟ مفيش MCP رسمي من Google. وNano Banana متاح أصلاً عن طريق Higgsfield MCP.
3. **لوحات H2 التلاتة:** تتشال من مراجع دنيا (العدد يبقى ١٠ من ٢٠) وتفضل في فولدر H2 بس؟
