# اللي محتاجه مني على الماك

دي كل حاجة لازم تعملها بنفسك. البرنامج والمساعد مش هيطلبوا منك أي حاجة مش مكتوبة هنا.

1. هات آخر نسخة من الفرع `claude/compassionate-darwin-q029ht` على الماك (git pull، أو أي طريقة بتجيب بيها الكود).
2. لو السكريبت قالك «ffmpeg مش موجود»: افتح Terminal واكتب `brew install ffmpeg`.
3. دبل كليك على `app/mac-setup.command`. لو الماك قال إن الملف مش موثوق: كليك يمين عليه، وبعدين «Open».
4. في شاشة «أول تشغيل»: سجّل دخول بحسابك في Higgsfield وSuno وRunway. كل زرار بيفتح صفحة الشركة نفسها، وبعد ما توافق ارجع للبرنامج.
5. لو ظهرلك سؤال من Keychain بخصوص «Ghorfa»: اختار «Always Allow».
6. لو الماك سأل إن كان node يستقبل اتصالات: اختار «Allow». البرنامج شغال على الماك بتاعك بس (127.0.0.1).
7. لو Claude Code مش متسجّل: افتح Terminal واكتب `claude` وسجّل دخول بحسابك. ده للفحص البصري وللإلهام.
8. ملف الماستر FLAC (`I_Am_The_World_v44_FINAL.flac`): اسحبه على صفحة الأغنية لما يجهز.
9. لو أي خطوة وقفت: ابعت صورة الشاشة أو الـ Terminal للمساعد.
